路线判别：赋能 ≠ 原生
两份输入稿（共享 Agent + 客户端 + 人查知识库）本质是「人的流程 + AI 工具」。原生路线把组织本身重画一遍：Agent 是常驻节点，流程跑在 Agent 网络上。同一个 openJiuwen/RAGFlow，组织方式不同，天花板不同。

治理红线与度量（打赏评比的数据底座）
红线管住风险，度量喂饱三件事：月度智能体打赏评比、管理层 ROI 汇报、组织记忆复利。所有指标来自节律层天然埋点，不额外填报。
🚫 涉密分级 L0/L1/L2：L2（图纸源文件 / 核心固件源码）永不出 PDM，Agent 只读元数据；外部模型仅接收 L0/L1 且过脱敏网关。
🚫 权限镜像原则：Agent 权限 ⊆ 所属人权限；Agent Prompt / Skill 对普通员工不可见，防 AI 资产外泄。
🚫 高风险人工闸：对外发送、资金 / 单据类操作、批量删改必须人确认；禁止人工绕过 Agent 直接粘贴涉密内容到公共 AI。
🚫 记忆即制度：会议不出纪要卡视为未开会；行动项无负责人纪要 Agent 拒收——组织规则写成 Agent 可执行的检查。
作战卡确认率 & 人工改写率：拆解质量信号 → 周度调优提示词。
纪要确认时长中位数 / 行动项按期完成率：组织执行力仪表盘，按部门排行。
卡处理量 · 响应时长 · 节省工时申报（抽验）：月度智能体打赏评比的判分依据，按数据不按 demo。
模型成本 / 部门：网关账单直出，ROI 汇报素材。

⚠ 开放问题（落地前需拍板）

  1. openJiuwen 对标准 A2A 协议的兼容度需实测；不足则自建轻量卡片路由【估 2 人周】。
  2. 钉钉回调需公网入口：FRP / 云代理 / 公网小服务器，取决于公司网络出口策略。
  3. 涉密分级（L0/L1/L2）由谁定义、图纸元数据的开放边界——需公司书面口径。
  4. ASR 选型：钉钉闪记导出（快，数据过钉钉云） vs 私有化 Whisper（可控，需 GPU）。
  5. 个人记忆的隐私边界：记了什么、谁能看、离职怎么销毁——需写入员工 AI 使用制度。
